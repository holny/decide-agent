# src/decide_agent/config — Layered Config + XDG Paths

**Role:** Layered config loader (defaults < user config < env vars) + runtime path resolution.

## STRUCTURE

```
config/
├── __init__.py
├── defaults.jsonc              # ★ Built-in defaults (read-only, package-shipped)
├── loader.py                  # load_config() + helpers (get_decision_model, get_data_dir, ...)
└── paths.py                   # Paths dataclass + XDG helpers + builtin_share_dirs
```

## WHERE TO LOOK

| Need | File | Notes |
|----|------|-------|
| Read any config value | `loader.py::load_config()` (lru_cache'd) | Merge defaults < user < env |
| Override via env var | `DECIDE_AGENT__SECTION__KEY=VALUE` (double underscore) | e.g. `DECIDE_AGENT__DECISION__CONFIDENCE_THRESHOLD=0.7` |
| Add a new config key | edit `defaults.jsonc`, add helper in `loader.py` | Helpers are typed getters (`get_data_dir() -> str`) |
| Resolve data dir | `loader.py::get_data_dir()` returns configured `paths.data_dir` | Empty string → XDG default |
| Write user config template | `loader.py::write_user_config()` | Used by `decide-agent init` |
| XDG paths | `paths.py::Paths.resolve(data_dir)` | Creates `sessions/`, `raw/`, `cache/`, `logs/`, `memory.db` |
| Builtin plugins/skills dirs | `paths.py::builtin_share_dirs()` | Returns `(plugins_dir, skills_dir)` |
| User config file location | `paths.py::user_config_file()` | `~/.config/decide-agent/config.yaml` |
| Skill search dirs | `paths.py::skill_search_dirs()` | `[builtin, user, project]` priority order |
| Migrate config version | `common/migrations.py::migrate(owner_dir)` | Uses `meta.json` version gate |

## CONVENTIONS

- **Config precedence (hard-coded)**: `defaults.jsonc < user config.yaml < env vars`. Env wins.
- **User config at `~/.config/decide-agent/config.yaml`** (XDG_CONFIG_HOME). Generated by `decide-agent init`.
- **`.env.example` documents API key names** — never commit actual keys.
- **Env var format**: `DECIDE_AGENT__<SECTION>__<KEY>=VALUE`. `__` is the section separator (NOT single `_`).
- **Env values parsed as YAML** — booleans, numbers, strings all work via `yaml.safe_load(value)`.
- **`load_config()` is `lru_cache`'d** — first call computes, subsequent calls cached. Tests must call `load_config.cache_clear()` or pass `user_config_path`.
- **`get_*` helpers are typed getters** — `get_data_dir() -> str`, `get_confidence_params() -> (float, float)`. Default values live in `defaults.jsonc`, not in helpers.

## ANTI-PATTERNS

- ❌ Reading `os.environ` directly outside `loader.py` — use the `get_*` helpers
- ❌ Editing `defaults.jsonc` for user customization — override via `~/.config/decide-agent/config.yaml`
- ❌ Committing `.env` or actual API keys
- ❌ Using `os.path.expanduser("~")` directly — use `Paths.resolve` / XDG helpers
- ❌ Mutating config dict in-place — `_deep_merge` returns a new dict

## NOTES

- **Data dir layout** (`~/.local/share/decide-agent/`):
  - `sessions/` — session state (recoverable)
  - `memory.db` — long-term memory (P2+ SQLite WAL)
  - `raw/` — large tool result offloads (`raw_data_ref` targets)
  - `cache/` — POI/weather response cache (TTL'd)
  - `logs/` — runtime logs
  - `evolved/` — Agent's only write zone (memory, judgments, weights)
  - `runtime/` — volatile (snapshots, cache, raw, tmp)
- **XDG overrides**: `XDG_DATA_HOME`, `XDG_CONFIG_HOME`. All `Paths.*` respect these.
- **`builtin_share_dirs()` resolves dynamically**:
  - Env var `DECIDE_AGENT_BUILTIN_DIR` set → use that
  - Repo root has `plugins/` + `skills/` → use those (dev mode)
  - Otherwise → site-packages `share/decide_agent/{plugins,skills}` (installed wheel)
- **wheel force-include**: `pyproject.toml` includes `plugins/` + `skills/` → `share/decide_agent/` in the wheel.
- **`lru_cache` on `load_config`** means tests passing different `user_config_path` may need to call with explicit path or clear cache.
- **Env values parsed as YAML** — `DECIDE_AGENT__DECISION__RECOMMEND_ALTERNATIVES=3` works as int; `DECIDE_AGENT__DECISION__DECISION_MODE=experience` as string.
