# 美食场景（Skill 模板）

## 关键词
吃饭 美食 吃 想吃 餐厅 饭店 吃饭的地方 嗨饭 早餐 午餐 晚餐 夜宵

## 场景说明
用户想吃饭/吃美食时启用。候选来源为地图 POI，核心维度为口味匹配、距离、价格、排队、天气适配。

## 追问话术
- 缺定位：方便告诉我你的位置吗？（选项：使用当前位置 / 手动输入地址）
- 缺口味偏好：今天想吃辣还是清淡？（选项：想吃辣 / 清淡 / 都可以）

## 输出格式
- 推荐 1 家 + 各维度得分 + 人话理由
- 备选 2 家 + 一句话理由
- 理由必须引用维度得分与用户偏好

## 禁忌点
- 用户忌口标签命中候选 tags → 直接过滤
- 人均超预算带上限 20% → 过滤
